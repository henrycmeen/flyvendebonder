# Spørsmål til Presis og NIBIO

Dette er en liste over spørsmål vi ønsker svar på når vi snakker med NIBIO/NLR eller leser dokumentasjonen deres.

## Om plattformen Presis

- Hvilke datatyper støtter Presis ved opplasting (dronebilder, satellitt, annet)?
- Hvilke filformater og oppløsninger anbefales for dronekartlegging?
- Hvordan prises tjenesten (per gård, per sesong, per areal)?
- Hvordan får bonden tilbake resultatene (nettkart, shapefiler, traktorterminal, rapporter)?
- Finnes det API eller eksport til standard formater (GeoTIFF, shapefile, CSV) som kan brukes til egne rapporter?
- Kan en tredjepart (som Flybendebønder) administrere opplastning og tilganger på vegne av bonden?

## Om arbeidsdeling mellom plattform og rådgiver

- Hvilke deler av tolkningen forventer NIBIO/NLR at rådgivere gjør, og hvilke er «innebygget» i plattformen?
- Er det rom i økosystemet for aktører som:
  - spesialiserer seg på datainnsamling (droneflyging),
  - pakker og visualiserer data for bonden og forsikringsselskapene?

## Om bondens hverdag

- Hvor krevende opplever de at det er for en typisk bonde å:
  - planlegge og fly drone selv,
  - laste opp data,
  - forstå kart og anbefalinger fra Presis?
- Hvilke typer støtte etterspør bøndene mest (kurs, «gjør det for meg», faste avtaler)?

## Videre bruk av data

- Hvilke rammer ligger rundt gjenbruk av drone- og analysedata (forskning, anonymiserte aggregat, kommersiell gjenbruk)?
- Hvordan håndteres personvern og eierskap til bildedata (bonden, NIBIO, tredjepart)?
- Kan historiske datasett enkelt brukes til før/etter‑analyser (for eksempel ved grøfting, kalking, endret drift)?
