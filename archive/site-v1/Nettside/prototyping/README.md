# Prototyping (lokalt)

Dette er et trygt område for prototyper ved siden av den eksisterende nettsiden. Ingenting her påvirker `Nettside/index.html`.

## Starte lokalt

Kjør en lokal server fra `Nettside/` (da fungerer video + symlinks til `assets/`):

```bash
cd Nettside
python3 -m http.server 8000
```

Åpne deretter:

- `http://localhost:8000/prototyping/`
- `http://localhost:8000/prototyping/v1/`
- `http://localhost:8000/prototyping/v2-pola/`
