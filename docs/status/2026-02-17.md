# Flyvendebønder – status 17. feb 2026

## Hva er ferdig nå

### App og UI
- React + TypeScript kartapp ligger i `apps/web-app`.
- Infosiden leverer nå `/` via `apps/info-site`.
- `vite`-aliaser og monorepo-oppsett er på plass.
- Demo vises på `/app/` med kart + sidepanel + tidslinje.
- Ny markerdesign med felter for Drone/Camera (ikonpinner) er aktiv.
- Kartvalg ligger i sidemeny:
  - OSM
  - Topografisk
  - Illustrert
  - Lys
  - Satellitt
- Kartjusteringer:
  - svart/hvitt toggle
  - vintage filter
  - eiendomsgrenser fra WMS (NIBIO)
- Brukerprofil vises i øverste område med redigeringsdialog.
- Teknisk logg er flyttet til innstillinger (ikke alltid synlig i hovedbildet).
- Marker-popup åpner bildet og grunninformasjon.

### Robusthet
- Kartfeil som brakk tidlig rendering er fikset.
- Appen bygger og startes (`npm run build`, `npm run dev`) med aktive ruter.
- Debug-tilstand viste tidligere konflikt i Leaflet (`subdomains: undefined`) som nå er rettet.
- Fotoanalyse er koblet til NIBIO-oppslag for AR5 + jordkvalitet (WMS `GetFeatureInfo`, WFS fallback).
- Analysepunkt i backend følger samme geometri som vises i kartet (estimert målpunkt ved retning/pitch, fallback punkt).
- Full backfill er kjørt på dagens database (`394` bilder, `394` prosessert, `0` feil).

### Drift
- Deploy/prepare scripts er i repo (`scripts/prepare-webroot.sh`, `scripts/deploy-flyvendebonder.sh`).
- Oppdatert README beskriver standard kjørsel + deploy.
