# Status 2026-07-16

## Kartbasert driftsareal

GitHub issue: 242

- Vanlig Kart har fått et tilgjengelig «Jorde»-verktøy for klikk eller oppslag i kartets sentrum.
- Oppslag er skrivebeskyttet og viser alle Geonorge-kandidater, matrikkel, areal, kilde og nøyaktighet før brukeren velger.
- Lagring krever admin og et eksplisitt valg mellom eid, leid og ikke angitt.
- Bekreftelsen henter kandidaten på nytt på serversiden; klienten får ikke levere autoritativ geometri eller matrikkeldata.
- Stabil kildeidentitet og databasebegrensning hindrer duplikatfelt. Endret kildegeometri oppdaterer et usplittet område i stedet for å lage en ny kopi.
- Preview og eksisterende koblinger er avgrenset til aktiv bruker. Eiernavn lagres eller vises ikke i MVP-en.
- En pågående lagring kan ikke skjules av Escape, kartklikk eller verktøybytte før resultatet er avklart og profilen er oppdatert.

Validering: målrettede backend- og migreringstester, frontend state-/konkurransetester, lint, produksjonsbygg, full worktree-validering, stack-smoke og manuell nettleserflyt.

## Lesbare kartkontroller på satellittfoto

GitHub issue: 241

- Satellittmodus bruker egne semantiske kontrollflater med stabil mørk bakgrunn, lys tekst og tydelige kantlinjer over både lyse og mørke flyfoto.
- Aktiv, inaktiv og deaktivert tilstand skilles med form, kantlinje og markør i tillegg til farge.
- Tastaturfokus har en tydelig dobbel fokusmarkør, også over detaljrike kartbilder.
- Kartfilterpanelet, jordeverktøyet og flytende status-/feilmeldinger følger samme satellittspesifikke kontrastregler.
- Standardkart og topografisk kart er uendret; reglene er avgrenset til `map-ui-satellite`.

Automatisert validering: kontrasttest mot både svart og hvitt underlag, frontendtester, lint, produksjonsbygg, 263 backendtester og 7/7 isolert stack-smoke.

## Åpen pilottilgang uten passord

GitHub issue: 271

- Produksjon åpner gårdsdata direkte uten tilgangskode eller innloggingscookie.
- Åpen tilgang er bundet til den ene eksplisitt konfigurerte pilotbrukeren; den velger aldri eier fra vilkårlige data.
- Standardoppsett, forks og miljøer uten eksplisitt aktivering er fortsatt lukket som før.
- Deploy verifiserer åpen tilgang, cookie-fri profil og korrekt eierbinding før en ny `main`-versjon regnes som produksjonsklar.

Validering: 263 backendtester i Python 3.13 og 3.9, frontendtester, lint, produksjonsbygg, lukket og åpen stack-smoke, read-only produksjonssmoke og manuell Chrome-kontroll.
